# thorfindev

Marketing website for **Thorfin Dev** — an engineering-led software studio building reliable infrastructure for commerce and finance.

## Overview

- **Stack**: Next.js (App Router), React 19, TypeScript, Vanilla CSS
- **Interactive UI**: Kinetic canvas particle grid with interactive cursor distortion and wave dynamics
- **Featured Projects**:
  - [Thorfin Space](https://thorfin.space) — Finance automation & ledger platform
  - [Ecommerce Hub](https://ecommerce-hub-mu.vercel.app/) — Multi-tenant commerce engine
  - [Rydway Web](https://rydway-web.rydway-space.workers.dev/) — Dispatch & fleet operations
  - [One & Only Cleaning](https://one-and-only-cleaning-services.vercel.app/) — On-demand service platform

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
